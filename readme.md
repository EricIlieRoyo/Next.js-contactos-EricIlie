Las principales diferencias de de Next.js son:

- El lenguaje de **JavaScript(Next.js)** permite arrancar el servidor una vez y se queda encendido escuchando peticiones a diferencia de **PHP** que tras cada petición reinicia. Por lo que el **JavaScript** es muy bueno para aplicaciones de tiempo real.

- En **Next.js** hace uso del mismo lenguaje en el servidor y el navegador el cual a través de **React** (una librería que te permite construir la interfaz visual a base de Componentes) por lo que puede conectarse a la base de datos.

- A diferencia de **Symphony** que las rutas se definen mediante atributos **Next.js** usa enrutamiento basado en archivos es decir **Next.js** crea automáticamente la ruta pública.

- Por último **Next** a diferencia del **Twig** de **Symphony** utiliza **JSX** en el cual puedes escribir **HTML** dentro de las funciones **JavaScript**.
